# Learning through Failure
This was a failed simple text game which is perfectly fine, failure generally teaches us more than success!

- Why did I fail?

Simply put I did not respect the amount of features that were being put into the game, especially the loading feature which I did not visualize at all until it completely failed the project.

- How to avoid this in the future

1. I would reccomend for my style of development for these class projects to always start with the database design first as that forces me to completely visualize how every data type should be shaped and what the limits of the design can be since the database will clearly show how the data will be able to be processed.
2. I would reccomend having the data live in the proper locations, by that I mean that the rooms did not have their names at all inside of themselves which made it impossible to reference which room the player was inside of after already being in the room.
3. Give proper respect to the hardest feature first. Instead of putting off the loading feature until the end, at least have a clear vision of how the loading will work from the very beginning as this will make all decisions related to the loading feature align with the eventual end goal. Since I did not appreciate the difficulty of the load feature I wrote myself into too many coners that made it impossible to properly implement it without redesigning the entire game.
